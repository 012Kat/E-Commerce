E-Commerce Website

🛍 Overview
A simple e-commerce frontend where users can browse products, add to cart, and see total price — all using vanilla JS, HTML, and CSS.

💡 Features
- Product display from JS array
- Add/remove from cart
- Cart total updates
- Clean, mobile-friendly design

🚀 Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
